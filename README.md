Project Summary: Yeong Sil – AI Memory Companion
Yeong Sil is a unique, voice-activated AI assistant designed to help people with memory challenges, such as Alzheimer’s or age-related cognitive decline. It acts as a caring companion that recognizes familiar faces, reminds users of important tasks, and holds natural conversations to reduce confusion and anxiety.

Key Features:
Wake Word Activation: Users invoke the assistant by saying “Hey Yeong Sil”, enabling hands-free interaction.

Face Recognition: Uses the device camera to identify family and friends, reminding users who they are seeing.

Voice Interaction: Listens to and answers user questions with natural speech powered by AI (GPT).

Reminders & Daily Assistance: Provides timely medication alerts, appointment reminders, and helpful prompts.

Caregiver Portal: A web app where family or caregivers can upload photos, set reminders, and manage the user’s memory profile.

Passive, Always-On: Runs seamlessly on a smartphone or tablet, allowing continuous support without user navigation.

Problem Solved:
Yeong Sil empowers individuals with memory impairments to regain independence and confidence by providing personalized memory assistance through natural, voice-based AI interactions — reducing reliance on constant human supervision.

Technology Stack:
Frontend: React.js for the caregiver portal, and React or WebView for the user interface.

Backend: Node.js, Express, MongoDB for data management.

AI & ML: Face recognition with TensorFlow.js or Face API.js, voice recognition and synthesis via Web Speech API, GPT for conversational AI.

Device: Runs on smartphones/tablets or optionally on edge devices for always-on capability.

Why It’s Unique:
Combines face recognition, AI conversation memory, and voice commands in a single, easy-to-use assistant.

Focuses on non-technical users, especially elderly people, with hands-free, intuitive use.

Bridges the gap between caregivers and patients via a secure, manageable web portal.
